# Campaign trainer portrait assets

Stage 2 supplies final original trainer portraits. Stage 1 deliberately contains no final artwork and no placeholder image files.

## Contract

- Keep portraits local in this directory; do not use remote image services.
- Recommended source framing: transparent-background **4:5** bust or half-body portrait.
- Recommended source export: **1024×1280**. The UI reduces assets through CSS.
- Keep the subject centered, with breathing room around hair and shoulders.
- Use a consistent style across all twenty identities.
- Do not embed text in the artwork.
